# Workflow Inspector Toolkit v0.1.0

An MIT-licensed local toolkit from **Workflow Inspector** for workflow handoff diagnostics and SaaS customer onboarding evidence.

## Included

- Validate normalized CSV and JSON workflow events.
- Calculate completed handoff waiting times and recorded onboarding durations.
- Show usable sample sizes and excluded or ambiguous pairs.
- Compare baseline and follow-up records with descriptive differences, not causal claims.
- Generate deterministic JSON and self-contained HTML reports.
- Run the synthetic examples without an account, API key or runtime dependency.

Python 3.11 or newer is required. Start with the [quickstart](https://github.com/WBZKLLC/workflow-inspector-toolkit/blob/v0.1.0/docs/quickstart.md), [metric definitions](https://github.com/WBZKLLC/workflow-inspector-toolkit/blob/v0.1.0/docs/metrics.md), [Handoff Diagnostic guide](https://github.com/WBZKLLC/workflow-inspector-toolkit/blob/v0.1.0/docs/handoff-diagnostic.md), and [architecture diagram](https://github.com/WBZKLLC/workflow-inspector-toolkit/blob/v0.1.0/docs/architecture.md).

## Verification and download

Publication runs the standard-library test suite and release checks against the source revision being released. The attached source ZIP is generated with `git archive` from that revision; the adjacent SHA-256 file verifies the download. The release source is not a prebuilt installer or a PyPI package.

All included activity examples are fictional. They are not customer results, independent product validation, industry benchmarks or evidence that an intervention caused improvement. No native CRM connection, hosted API client, proprietary score or telemetry is included.
