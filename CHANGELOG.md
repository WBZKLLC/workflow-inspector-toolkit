# Changelog

## 0.1.0: initial toolkit

Local CSV/JSON validation for a four-event onboarding subset; descriptive handoff and workflow timing; explicit ownership-observation counts; visible pair exclusions and sample sizes; baseline/follow-up comparison; deterministic JSON and self-contained HTML reports; a local Python library; synthetic examples; and automated tests.

This version introduces no hosted API client, native vendor connector, proprietary scoring method, or remote telemetry.
